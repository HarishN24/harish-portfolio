# 🌐 Harish Neelapala — Developer Portfolio

A modern and responsive personal portfolio website built to showcase my **skills, projects, education, certifications, and professional journey** as a Full Stack Developer.

This portfolio is designed with a **code editor / file explorer inspired UI**, providing a unique developer experience. It includes smooth animations, responsive design, and interactive sections to present my technical skills and projects professionally.

# 🚀 Deployment

This project is deployed using **Vercel**.

Deployment Steps:

1. Push the project code to GitHub
2. Connect the repository with Vercel
3. Configure build command:

```bash
npm run build
```

4. Deploy successfully

Live Application:

```
https://harish-portfolio-tan.vercel.app/
```
